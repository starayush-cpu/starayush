# starayush

Personal link hub for Ayush (starayush). Dark page, orange accent. All socials in one place: X, GitHub, Bluesky, Binance Square, YouTube.

## Latest Posts

The page loads the latest posts live in the visitor's browser on every visit: Bluesky via its free public API, YouTube via the channel RSS feed. If a feed cannot load, the section shows a link to the profile or channel instead of fake posts.

## Deploy on Vercel

Import this repo in Vercel, set Framework Preset to Other, leave the build command empty, and deploy. `index.html` sits at the repo root.
